### Item 7 — every public claim compared against its evidence · human

**This item failed on first read, and that is the finding of this packet.**

`README.md`'s "What this is" section stated: *"Nothing here runs yet: this repository currently holds
a roadmap, the governance and design documents, and **an empty package skeleton**."*

That sentence was true when EP-2 wrote it and false when EP-8 read it. Between them, EP-5 landed the
rights and licence checks, EP-6 landed nine leak scanners and a CI job, and EP-7 landed the storage
roots, the read-only inventory and the reserve guards. The package is not empty and has not been for
two briefs. **No scanner could have caught this**: the badge check confirms the badge resolves to a
fully ticked evidence file, and it did; the claim that drifted was a sentence about the tree, and a
sentence about the tree is exactly what item 7 exists to read.

**Corrected in the commit this packet covers.** The paragraph now says what is there — a CLI and
three packages, every one of which checks the project rather than being it — and says plainly that
none of the tool runs. `epppsynth/README.md` carried the same stale claim and was corrected with it.
`epppsynth/docs/evidence/design.md`'s "No engine exists" box carried the same stale evidence
(`__init__.py` and `cli.py` only); the **box did not change state**, its evidence was rewritten, and
the file records both facts with the date.

**The badge did not move and could not.** P0 produced no engine: no registry, no composer, no
selection, no abstention chain, no renderer, no interface. `status: design` is correct and
`--status` now asserts that the badge, the README status paragraph, the evidence file and
`CITATION.cff` all agree.
